## <a id="content1">数据库</a>

本章先认识两种常用数据库，再完成 MySQL 的安装、建库建表，最后看看读取数据库的几种方式。    

#### **一、常用数据库对比**   

| 对比项 | SQLite | MySQL |
| --- | --- | --- |
| 类型 | 嵌入式数据库 | 专业级数据库服务 |
| 适用场景 | 本地 / 单机使用，比如手机 App 本地存储 | 网站、后台系统、高并发业务 |
| 数据文件 | `xx.db` 文件，可以直接读取 | `xx.ibd` 文件，不能直接读取，需要导入 |
| 本机准备 | mac 自带 sqlite | 需要安装并启动服务 |

SQLite 使用单个 `.db` 文件存储，复制文件即可迁移，但只适合单机场景。    

MySQL 的 `.ibd` 文件不能直接打开：数据库中的 ibd 文件都带有身份标识，外来数据库文件无法直接识别。    
所以需要先在 MySQL 中创建一个新的 `yy.ibd`（建库建表），再把 `xx.ibd` 的数据导入，才能读取。

#### **三、数据库的读取方式**    

1、**可视化工具**：用 Navicat 等客户端连接数据库，填好地址、端口、账号密码即可读取。

2、**命令行**：连接 MySQL 后，通过指令和 SQL 直接读取。

3、**IDEA Database**：IDEA 自带的数据库工具，但可视化功能需要专业版。

4、**代码读取**：Spring Boot 整合 MySQL，通过代码读取数据库（下一章介绍）。     



#### **四、补充**    

正常的商业级开发，数据库是不会部署在本地的，一般是部署在云服务器。    
后台开发者，只需要连接数据库就可以了。      


## <a id="content2">Spring Boot 整合 mysql(Spring Boot 自带的 JdbcTemplate)</a>

JDBC = Java Database Connectivity 

JDBC：接口标准（契约）       
数据库驱动：mysql-connector-j 是 JDBC 接口的实现（真正干活和数据库通信的）    
JdbcTemplate / MyBatis / SpringDataJPA：工具 / 框架层，包装 JDBC 调用，简化开发，**它们是上层封装**    

Spring Boot 官方提供了开箱即用的 JdbcTemplate 工具类，它对原生 JDBC 操作进行了轻量封装，大幅简化了数据库连接、语句创建、资源释放等重复样板代码的编写流程，让开发者可以专注于 SQL 本身的业务逻辑实现。

整合流程只有三步：**加依赖 → 配置数据源 → 写测试验证**。    
前提：MySQL 服务已启动，并且已经按上一章创建好 `HelloSpring` 数据库和 `user` 表。    

#### **一、添加依赖**   

在 `pom.xml` 的 `<dependencies>` 中添加下面的依赖，各依赖的作用和必要性如下：    

| 依赖 | 作用 | 是否必需 |
| --- | --- | --- |
| `mysql-connector-j` | Java 程序与 MySQL 通信的驱动，没有它连不上数据库<br>它是JDBC接口规范的实现 | 必需 |
| `spring-boot-starter-jdbc` | 提供 `JdbcTemplate`、连接池（默认 HikariCP）和事务管理<br>它是上层封装，包装了JDBC的调用 | 必需 |
| `jakarta.annotation-api` | 提供 `@Resource` 注解，用于注入JdbcTemplate对象 | 必需 |
| `lombok` | 自动生成 getter/setter/toString，减少样板代码 | 强烈推荐(可选) |
| `mybatis-plus-boot-starter` | 不写 SQL 即可完成增删改查，本章用不到，下一章详解 | 可选 |
| `mybatis-plus-generator`、`freemarker` | 代码生成器及其模板引擎 | 可选 |

`pom.xml` 完整配置：  

```text
<dependencies>
        <!--
        作用：帮你自动生成 getter、setter、toString、构造方法不用手写一堆 getXXX() setXXX()，代码更干净。
        必须吗？ 非常推荐，几乎所有项目都用。
        -->
        <dependency>
            <groupId>org.projectlombok</groupId>
            <artifactId>lombok</artifactId>
            <version>1.18.30</version>
            <scope>provided</scope>
        </dependency>


        <!--引入jdbc stater 目的是使用JDBC模板接口-->
        <!--
        作用：Spring 自带的简单数据库操作工具可以用 JdbcTemplate 操作数据库。
        必须吗？ 你现在可以删掉！因为你用了 MyBatis-Plus，它已经包含了这个功能。
        -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-jdbc</artifactId>
        </dependency>


        <!-- MySQL 驱动（新版，必须用这个） -->
        <!--
        作用：Java 程序和 MySQL 说话的 “翻译官”没有它，SpringBoot 根本连不上数据库。
        必须吗？ 必须！连数据库必用。
        -->
        <dependency>
            <groupId>com.mysql</groupId>
            <artifactId>mysql-connector-j</artifactId>
            <scope>runtime</scope>
        </dependency>


        <!--mybatis-plus-->
        <!--
        作用：数据库操作神器！不用写 SQL，就能实现增删改查。你现在的项目核心依赖。
        必须吗？ 必须！你就是用它操作 user 表。
        -->
        <dependency>
            <groupId>com.baomidou</groupId>
            <artifactId>mybatis-plus-boot-starter</artifactId>
            <version>3.5.3.1</version>
        </dependency>


        <!--代码生成器（可选）-->
        <!--
        作用 自动生成：实体类、Mapper、Service、Controller输入表名 → 一键生成全套代码。
        必须吗？新手可以不用，属于辅助工具。
        -->
        <dependency>
            <groupId>com.baomidou</groupId>
            <artifactId>mybatis-plus-generator</artifactId>
            <version>3.5.3.1</version>
        </dependency>


        <!-- 代码生成器需要模板引擎 -->
        <!--
        作用：代码生成器生成代码时需要的模板。
        必须吗？不用代码生成器就可以删。
        -->
        <dependency>
            <groupId>org.freemarker</groupId>
            <artifactId>freemarker</artifactId>
        </dependency>


        <!--
        作用：解决你最开始的报错：Cannot resolve symbol 'Resource'让你能使用 @Resource 注解注入对象。
        必须吗？必须！
        -->
        <dependency>
            <groupId>jakarta.annotation</groupId>
            <artifactId>jakarta.annotation-api</artifactId>
            <version>2.1.1</version>
        </dependency>
</dependencies>
```

#### **二、配置数据源**   

配置文件位于 `HelloSpring/config/application.yam`，每一行的作用见注释：    

```properties
##jdbc:mysql://             用 JDBC 协议连接 MySQL
#localhost                  数据库在本机（你自己的电脑）
#3306                       MySQL 默认端口号（固定不用改）
#HelloSpring                你要连接的数据库名字（就是你创建的那个库）
#serverTimezone=GMT%2B8     设置时区为 东八区（中国时间），必须加，否则报错
#useUnicode=true            使用 Unicode 字符集
#characterEncoding=utf-8    编码用 UTF-8，防止中文乱码
spring.datasource.url=jdbc:mysql://localhost:3306/HelloSpring?serverTimezone=GMT%2B8&useUnicode=true&characterEncoding=utf-8
#MySQL 的登录用户名
spring.datasource.username=root
#MySQL 登录密码（改成你自己设置的 root 密码）
spring.datasource.password=123456
#MySQL 驱动类作用：让 Java 程序能 “听懂” MySQL 的语言
spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver
```

#### **三、编写测试用例验证**   

测试类位于 `src/test/java/com/lxy/hellospring/HelloSpringApplicationTests.java`。    

- `@SpringBootTest`：启动完整的 Spring 容器，这样测试类里才能注入 `JdbcTemplate`。
- `@Resource`：把容器中的 `JdbcTemplate` 注入进来。
- `RowMapper`：把结果集中的一行数据映射成一个 `UserEntity` 对象，列名要和实体字段一一对应。

```java
package com.lxy.hellospring;
import com.lxy.hellospring.module.user.model.UserEntity;
import jakarta.annotation.Resource;
import org.junit.jupiter.api.Test;
import org.springframework.boot.test.context.SpringBootTest;
import lombok.extern.slf4j.Slf4j;
import org.springframework.jdbc.core.JdbcTemplate;
import org.springframework.jdbc.core.RowMapper;
import java.sql.ResultSet;
import java.sql.SQLException;
import java.util.List;




@SpringBootTest
@Slf4j
class HelloSpringApplicationTests {

    @Resource
    private JdbcTemplate jdbcTemplate;


    @Test
    void contextLoads() {
        String sql ="select * from user";
        List<UserEntity> users = jdbcTemplate.query(sql, new RowMapper<UserEntity>() {
            @Override
            public UserEntity mapRow(ResultSet rs, int rowNum) throws SQLException {
                UserEntity user = new UserEntity();
                user.setId(rs.getInt("id"));
                user.setAge(rs.getInt("age"));
                user.setName(rs.getString("name"));
                user.setSex(rs.getString("sex"));
                user.setAddress(rs.getString("address"));
                user.setDescribes(rs.getString("describes"));
                user.setImage(rs.getString("image"));
                return user;
            }
        });
        log.info("查询成功");
        users.forEach(p->{
            log.info("用户{}",p);
        });
    }
}
```

运行测试后，控制台会输出三条用户数据，说明 Spring Boot 已经成功连上 MySQL 并完成查询：    

```text
查询成功
用户UserEntity(id=1, name=刘亦菲, age=70, sex=女, address=上海闵行, describes=这是db1的用户, image=./template/image/刘亦菲.jpg)
用户UserEntity(id=2, name=杨幂, age=20, sex=女, address=北京朝阳, describes=这是db1的用户, image=./template/image/杨幂.jpg)
用户UserEntity(id=3, name=彭于晏, age=30, sex=男, address=河北邯郸, describes=这是db1的用户, image=./template/image/彭于晏.jpg)
```

本章用的是 Spring Boot 自带的 `JdbcTemplate`：SQL 要手写，结果集要自己映射。    
实际项目更常用下一章的 MyBatis-Plus，它把这些重复工作都省掉了。    


## <a id="content3">Spring Boot 整合MyBatis和Druid</a>

使用了MyBatis就不需要使用jdbc了。MyBatis包含了jdbc。          
使用了MyBatis-plus就需需要使用MyBatis了。MyBatis-plus包含了MyBatis。       
Druid可以替换默认的连接池HikariCP，另外提供了监控和统计功能。          

```text
        <!--
        一、Druid介绍
        是阿里巴巴开源的Java 数据库连接池，同时也是一套集监控、统计、安全防御于一体的数据库中间件，专为高并发、大规模企业级场景设计。

        二、作用
        管理数据库连接（最核心），可以用它替换默认自带 HikariCP 连接池。
        监控 SQL 执行
        防 SQL 注入
        boot -3 是专门给 Spring Boot 3 专用
        -->
        <dependency>
            <groupId>com.alibaba</groupId>
            <artifactId>druid-spring-boot-3-starter</artifactId>
            <version>1.2.28</version>
        </dependency>


        <!--
        一、mybatis-plus-boot-starter介绍
        它是 MyBatis-Plus（第三方增强工具） 的启动器，完全包含并大幅扩展了MyBatis的功能。

        二、作用
        数据库操作神器！不用写 SQL，不用写注解，不用使用xml配置文件，就能操作数据库。
        默认实现了增删改查功能(CRUD),这些功能也不用写SQL。

        三、必须吗？
        企业级开发中经常使用。

        四、版本冲突
        mybatis-plus-boot-starter内部依赖的mybatis-spring版本是2.12.2，它与spring boot 3.x有版本冲突
        所以在下面直接指定了mybatis-spring为3.0.3
        -->
        <dependency>
            <groupId>com.baomidou</groupId>
            <artifactId>mybatis-plus-boot-starter</artifactId>
            <version>3.5.16</version>
        </dependency>


        <!--
        一、mybatis介绍
        mybatis-spring-boot-starter 是 MyBatis 官方的 Spring Boot 启动器，提供基础整合能力；
        MyBatis 是一款 Java 生态里的「数据库持久层框架」，专门用来帮你在 Java 代码里操作数据库

        二、作用
        MyBatis 就是简化 JDBC 开发的工具，它帮你把繁琐的重复代码全封装好。
        可以通过注解或者xml配置文件的方式操作数据库

        三、必须吗？
        你现在可以删掉！因为 MyBatis-Plus，完全包含了mybatis。
        -->
        <dependency>
            <groupId>org.mybatis.spring.boot</groupId>
            <artifactId>mybatis-spring-boot-starter</artifactId>
            <version>2.1.1</version>
        </dependency>



        <!--
        一、spring-boot-starter-jdbc介绍
        Spring 操作数据库的底层核心支持，它不负责写 SQL，只负责连接、执行、事务

        二、作用
        1、连接池(默认)
        2、事务
        3、JdbcTemplate：原生 JDBC 要写：加载驱动、获取连接、创建 Statement、执行 SQL、处理结果集、关闭资源……用 JdbcTemplate 只需要一行

        三、必须吗？
        MyBatis / MyBatis-Plus 内部已包含它，不用重复引
        你现在可以删掉！因为你用了 MyBatis-Plus，它已经包含了这个功能。
        -->
        <dependency>
            <groupId>org.springframework.boot</groupId>
            <artifactId>spring-boot-starter-jdbc</artifactId>
        </dependency>




        <!--
        一、mybatis-spring介绍
        Spring 不认识 MyBatis 的 Mapper！
        Spring 不知道 UserMapper 是什么东西，不会创建它，不会管理它，更不能注入给 Service。

        二、作用
        mybatis-spring 就是中间翻译官 + 胶水.
        它告诉Spring：“这些 Mapper 接口是特殊的类，你要帮我创建、管理、注入！”
        -->
        <dependency>
            <groupId>org.mybatis</groupId>
            <artifactId>mybatis-spring</artifactId>
            <version>3.0.3</version>
        </dependency>


        <!--
        一、MySQL介绍
        驱动（新版，必须用这个）

        二、作用
        Java 程序和 MySQL 说话的 “翻译官”没有它，SpringBoot 根本连不上数据库。

        三、必须吗？
        必须！连数据库必用。
        -->
        <dependency>
            <groupId>com.mysql</groupId>
            <artifactId>mysql-connector-j</artifactId>
            <scope>runtime</scope>
        </dependency>
```
